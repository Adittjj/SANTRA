SANTRA - how to run (Mac)

1. Make sure MongoDB is running:   brew services start mongodb-community
2. Open Terminal and go into this folder:   cd ~/Downloads/SANTRA   (use your real folder name)
3. Install packages (first time only):   npm install
4. Load the products (first time only):   npm run seed
5. Start the website:   npm start
6. Open http://localhost:3000

Stop the server with Ctrl + C.
The .env file is hidden on Mac. Press Cmd + Shift + . in Finder to see it.
